# 机器视觉

基于 OpenCV（C++）的机器视觉计数练习集，共三个项目。三个程序都遵循同一套思路：**图像预处理 → 自适应分割 → 几何特征筛选 → 计数与标注**，所有阈值参数均由图像自身统计推导，不写死绝对数值，因此更换分辨率、明暗、光照条件仍然可用。

| 项目 | 目标 | 输入 | 方法要点 |
|---|---|---|---|
| [回形针计数](回形针计数) | 统计回形针数量 | `1.png` | 背景均衡 + 双极性 Otsu + 实心度选极性 + 连通域面积聚类 |
| [硬币计数](硬币计数) | 统计硬币数量 | `2.png` | 霍夫圆检测 + 半径范围自适应 |
| [完整圆孔计数](完整圆孔计数) | 标记完整圆孔 | `3.png` | Otsu + 圆形度筛选 + 基准面积两阶段中位数 + 贴边判为残缺 |

## 目录结构

```
机器视觉/
├── 回形针计数/        回形针计数.cpp  + 1.png + count_result.png
├── 硬币计数/          硬币计数.cpp    + 2.png + coin_result.png
└── 完整圆孔计数/      完整圆孔计数.cpp + 3.png + hole_result.png
```

每个目录都是一份可以直接用 Visual Studio 打开的工程：`.slnx` 解决方案 + `.vcxproj` 项目 + `Opencv4.6.0.props` 属性表（OpenCV 路径需按本机调整）。

## 编译与运行

1. 安装 OpenCV（本工程基于 **4.6.0**），确认属性表中的包含目录、库目录与实际安装路径一致；
2. 用 Visual Studio 打开对应目录下的 `.slnx`，选择 x64 平台生成；
3. 运行后控制台输出检测到的数量，同时在工程目录生成标注结果图：
   - 回形针 → `count_result.png`
   - 硬币 → `coin_result.png`
   - 完整圆孔 → `hole_result.png`

也可以命令行传入图片路径：`程序名.exe 图片路径`。

## 通用设计说明

- **尺度归一**：长边统一缩到 900px 以内再处理，参数与分辨率解耦，绘制时坐标再映射回原图；
- **背景均衡**：大尺度高斯估计背景后相减，抑制光照不均、暗角与阴影；
- **极性自适应**：同时生成"暗物体 / 亮物体"两种候选掩膜，按前景占比或实心度自动选择；
- **基准尺寸自适应**：以连通域面积的中位数（两阶段，先滤斑点、再滤粘连块）作为"单个物体多大"的基准，所有面积阈值都是它的倍数；
- **完整性判定**：接触图像边界的物体视为被画框裁切，标 `partial` 不计入数量。
